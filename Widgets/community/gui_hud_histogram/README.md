# FFA Timeseries HUD

A spectator and player HUD widget for **Beyond All Reason** that tracks all active players and plots smooth time-series line charts for the top 5 players based on Army Value (AV).

---

## Features
* **Multi-Metric Panels:** Displays 6 real-time metrics in a grid layout (Metal Income, Energy Income, Build Power, Stored Metal, Army Value, and Defense Value)[cite: 1].
* **Top 5 Tracking:** Dynamically identifies and tracks the top 5 players by Army Value[cite: 1].
* **Catmull-Rom Smoothing:** Renders smooth curves using Catmull-Rom spline interpolation with custom subdivisions[cite: 1].
* **10-Minute History:** Maintains and plots the sliding history of the last 10 minutes of gameplay[cite: 1].
* **Interactive UI:** Supports click-and-drag repositioning anywhere on the screen[cite: 1].
